# HyperOS Torch 255 v1.6.0

本版正式发布多机型接口自动探测与兼容性诊断，保留 HyperOS 原生手电筒和亮度滑条，无需 LSPosed 或 Zygisk。

## 更新内容

- 取消安装机型白名单，自动枚举 LED 节点、读取实际亮度范围，并去除符号链接重复项。
- 查找 odm、vendor、product 等分区及 camera 子目录中的 CamX 配置，识别专用温度传感器。
- 已校准的 pudding / SM8850 按校准配置选择持续照明通道；未知机型、接口不完整或多候选未明确时保留原厂策略，并提供报告。
- 修复 Android Shell 的 LINES 变量冲突、三个闪光灯通道导致的误判，以及相对路径启动导致的代理挂载失败。
- 开机和 OTA 后重新检测接口，Magisk 操作页显示候选路径、量程和未启用原因。
- 保留传感器失联降档、80/75°C 回滞、用户调暗优先和驱动关灯后不重开的处理。

## 安装

1. 下载 `HyperOS-Torch-255-v1.6.0.zip`，通过 Magisk 安装并正常重启。
2. 打开模块“操作”，检查当前状态和兼容性报告。
3. 从 alpha.2 可直接升级，内部版本号已递增；需要恢复原厂策略时禁用或卸载后重启。

## 验证与兼容范围

36 项回归测试通过；pudding / Android 17 已完成本轮实机发布验证。原生最高档五次采样均为 brightness=255、strobe=1，关灯后均为 0，PowerKeeper 私有代理随开关灯挂载和移除，后台仅一个守护进程。

其他机型可以安装和诊断，但 500 mA 增强配置目前仍只适用于已校准的 pudding 硬件。温控状态机另经手机临时文件模拟验证，不代表实物高温和长期寿命测试；多机型与长期点亮还需要进一步验证。

## English

Stable release of capability-based interface discovery and compatibility diagnostics. The module retains the native HyperOS torch and slider without requiring LSPosed or Zygisk.

- Detects LED paths and brightness ranges, resolves aliases, scans multi-partition CamX files, and identifies dedicated thermal sensors.
- Fixes the Android Shell LINES-variable collision, calibrated three-channel selection, and relative-path namespace mounting.
- Rechecks interfaces at boot and after OTA. Unknown or ambiguous hardware retains stock behavior with a diagnostic report.
- Passes 36 regression tests and the pudding / Android 17 release validation. Five short maximum-strength samples read 255/1; switch-off returned both controls to zero. The private PowerKeeper filter was mounted and removed with the torch session.
- Install the ZIP using Magisk and reboot. Direct upgrades from alpha.2 are supported. The 500 mA profile remains limited to calibrated pudding hardware; multi-device and long-duration validation are still pending.
